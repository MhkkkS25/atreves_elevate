# 📌 Overview

AtreVes Elevate is a responsive healthcare and pharmaceutical company website focused on presenting:

- Company profile
- Pharmaceutical capabilities
- Product development expertise
- Leadership section
- Gallery showcase
- Contact and partnership opportunities

The project emphasizes clean UI/UX, responsive layouts, and modern frontend architecture.

---

# 🚀 Features

- Responsive modern UI
- React + TypeScript architecture
- Tailwind CSS styling
- Dynamic image gallery
- Leadership/About sections
- Capability showcase cards
- Contact page with validation
- Vite fast build setup
- Mobile-friendly layouts
- Smooth hover animations and transitions

---

# 🛠 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
- React Router DOM
- Zod Validation

# 📸 Gallery System

The gallery dynamically loads all images from:

```bash
src/assets/Gallery
```

Supported formats:

- jpg
- jpeg
- png
- webp

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Mhkkks/atreves_elevate.git
```

Move into project folder:

```bash
cd atreves_elevate
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

# 📦 Build For Production

```bash
npm run build
```
